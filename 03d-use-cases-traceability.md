3.4   Initial use cases 

 

Six candidate use cases were drawn; one (UC-04 Take Quiz) was merged into UC-03, leaving the five shown. 
Each one starts with the student and ends when the student has something of value: materials ready, a library organized, 
a working setup, an answer, or a scored practice quiz. 

UC-01 Import Course Materials · UC-02 Ask a Question About Course Materials · UC-03 Practice with a Generated Quiz · 
UC-05 Manage Course Library (create courses, remove materials) · UC-06 Set Up Study-Wise for First Use. 

Note on relationships and numbering. We first drew "Generate Quiz" (UC-03) and "Take Quiz" (UC-04) separately, 
linked by «include». A generated quiz that is never taken gives the student nothing, so generating a quiz is a step, 
not a goal. We merged them into UC-03 and retired the number UC-04 so identifiers stay stable. No other «include» or «extend» 
relationship survived the same test. "Search materials" and "Call model" are steps inside UC-02 and UC-03, not use cases.
