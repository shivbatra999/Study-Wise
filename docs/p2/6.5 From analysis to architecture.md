### 6.5 From analysis to architecture

| Analysis object (5.1 and 5.2) | Component that owns it (6.3) | Note |
| :--- | :--- | :--- |
| Course, Material, PageOrSlide | CourseLibrary | Stored through LocalStore |
| Passage | PassageIndex | Created by MaterialIngestor, then handed to PassageIndex |
| PassageFinder | PassageIndex | Interaction object realized by the component |
| Citation | PassageIndex | Built from a passage’s material name and page number; carried inside Answer and QuizQuestion |
| Question, Answer | AnswerService | Not stored after display (no requirement asks for history) |
| QuestionHandler | AnswerService | Interaction object realized by the component |
| Quiz, QuizQuestion, Option, QuizResult | QuizService | Kept after submission through LocalStore (FR-17, CH-20) |
| QuizMaster | QuizService | Interaction object realized by the component |
| Local LLM runtime | External | Reached only through RuntimeGateway |
| Student (actor) | StudyUI | The actor interacts through StudyUI |
