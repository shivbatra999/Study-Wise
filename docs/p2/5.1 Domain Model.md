### 5.1 Domain Model

| Class | What it represents | Key attributes | Associations (with multiplicity) | 
| ----- | ----- | ----- | ----- | 
| Course | A named collection of materials the student creates (section 1.3) | name, /number of materials (derived) | contains 0..\* Material; 0..\* Question asked in it; 0..\* Quiz practised in it | 
| Material | One PDF or PowerPoint file imported into a course | name, type (PDF or PowerPoint), number of pages or slides, ready for questions | belongs to 1 Course; has 1..\* PageOrSlide; drawn from by 0..\* Quiz | 
| PageOrSlide | One page of a PDF or one slide of a PowerPoint | number | belongs to 1 Material; contains 0..\* Passage | 
| Passage | A piece of text from one page or slide, the unit an answer or question is built from | text | lies on 1 PageOrSlide; pointed to by 0..\* Citation | 
| Question | A question the student types about one course | text | asked in 1 Course; answered by 0..1 Answer (none when no material covers it) | 
| Answer | The response shown to the student | text | answers 1 Question; cites 1..\* Citation | 
| Citation | Where a fact came from | material name, page or slide number | points to 1 Passage; belongs to 0..1 Answer or 0..1 QuizQuestion | 
| Quiz | One practice quiz the student starts | format (multiple choice or short answer), number of questions | practised in 1 Course; draws from 1..\* Material; contains 1..20 QuizQuestion; scored as 0..1 QuizResult | 
| QuizQuestion | One question in a quiz | text, model answer (short answer only), student answer (short answer only) | in 1 Quiz; offers 0..4 Option (4 for multiple choice, 0 for short answer); sourced by 1 Citation | 
| Option | One choice in a multiple-choice question | text, is correct, is chosen | belongs to 1 QuizQuestion | 
| QuizResult | The score of a submitted multiple-choice quiz | number correct, total | scores 1 Quiz | 

“Chosen materials” in UC-03 is modelled as the association Quiz *draws from* Material, not as an attribute, because it names other objects rather than a value (see K1 in 5.3).
